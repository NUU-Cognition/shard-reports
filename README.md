# Reports

Create and organize reports - research findings, code reviews, concept explainers

## Structure

```
Shards/(Dev) Reports/
  shard.yaml              # Manifest
  init-rpt.md    # Init file — shard context
  skills/                 # sk-rpt-{name}.md
  workflows/              # wkfl-rpt-{name}.md
  templates/              # tmp-rpt-{name}.md
  knowledge/              # knw-rpt-{name}.md
  assets/                 # ast-rpt-{name}.{ext}
  install/                # Files to install into Mesh/
```
